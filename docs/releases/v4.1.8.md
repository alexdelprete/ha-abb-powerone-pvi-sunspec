# Release Notes - v4.1.8

## What's Changed

Maintenance release adding local brand images and repository health fixes.

### ✨ Improvements

- **Added local brand images** - New [brand/](custom_components/abb_powerone_pvi_sunspec/brand/) folder inside the integration directory (`icon.png`, `icon@2x.png`, `logo.png`, `logo@2x.png`)
  - Since Home Assistant 2026.3, brand images bundled with the integration are served locally and take priority over the (now legacy for custom integrations) home-assistant/brands CDN
  - Icons now display on the Integrations page and device pages without any external submission

### 🐛 Bug Fixes

- **Fixed hassfest validation** - Removed URLs from config flow descriptions in translations (newer hassfest rejects them); wording now matches the newer integrations
- **Modernized `Endian` enum** - Converted from `str, Enum` mixin to `enum.StrEnum` (ruff UP042); decoding behavior verified unchanged

### 🔧 CI/CD Improvements

- **Fixed workflow authentication** - Removed references to the expired `WORKFLOW_PAT` secret from all workflows; checkout now uses the default `github.token` (this had broken the automated release asset upload for v4.1.7)
- **Modernized release workflow** - Aligned with the newer integrations: version validation step (tag vs `manifest.json` vs `const.py`), `actions/checkout@v7`, `softprops/action-gh-release@v3.0.2`
- **Fixed Lint workflow** - Excluded `docs/` scaffolding scripts from ruff; added `PLR0917` to the ignore list (matching HA core); Python 3.14 runner

### 📦 Dependencies

- Bumped `homeassistant` development dependency from 2025.10.2 to 2026.8.1, resolving all 3 open Dependabot security alerts (1 high, 2 low — all in the dev dependency, none affecting the shipped integration)
- Dependabot updates: ruff 0.16.2, colorlog 6.12.0, pymodbus >= 3.14.0 (dev requirements)

### ⚠️ Breaking Changes

**None** - This is a backwards-compatible maintenance release.

### 🚀 Upgrade Notes

- Safe to upgrade from v4.1.7
- Brand icons require Home Assistant 2026.3 or newer to display (older versions simply ignore the folder)
- No configuration changes required
