# Release Notes - v4.1.7

## What's Changed

This is a critical bug fix release restoring compatibility with pymodbus 3.13.0 and newer.

### 🐛 Critical Bug Fixes

- **Fixed integration failing to load with pymodbus >= 3.13.0**
  - pymodbus 3.13.0 removed the module-level helpers `pack_bitstring` and `unpack_bitstring` from `pymodbus.pdu.pdu`
  - The vendored payload module [pymodbus_payload.py](custom_components/abb_powerone_pvi_sunspec/pymodbus_payload.py) still imported them from there, so on fresh installs (where pip resolves the latest pymodbus satisfying `>=3.11.2`) the integration failed to load with:

    ```text
    Error occurred loading flow for integration abb_powerone_pvi_sunspec:
    cannot import name 'pack_bitstring' from 'pymodbus.pdu.pdu'
    ```

  - Both helpers are now vendored directly into `pymodbus_payload.py` (taken from pymodbus 3.12.0, the last version that provided them), removing the dependency on pymodbus internals
  - Verified against pymodbus 3.14.0: module imports and register decoding work correctly
  - Reported in the [community forum thread](https://community.home-assistant.io/t/custom-component-abb-power-one-fimer-pv-inverters-sunspec-modbus-tcp/316363/450)

### ⚠️ Breaking Changes

**None** - This is a backwards-compatible bug fix release.

### 🚀 Upgrade Notes

- Safe to upgrade from v4.1.6
- Compatible with both older (>= 3.11.2) and current (3.13+/3.14+) pymodbus versions
- No configuration changes required
